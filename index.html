Viola for Mac

A refined music player for your Mac. Open and play music files from anywhere with effortless control.

Seamless File Playback

Plays music from iTunes Music folder or any location. Add folders or individual files via browser, drag-and-drop, or direct selection. Protected formats like M4P excluded.

Dynamic Playlists

Build playlists instantly by clicking folders or selecting tracks. Rearrange by drag, shuffle randomly, or save to file for quick access.

Precise Metadata Editing

Edit and save metadata directly. Converts to M4A on save. Excludes Apple Music-specific data and uneditable formats.

Advanced Equalizer

Fine-tune audio with frequency band adjustments. Save custom presets for instant recall.

Menu Bar Mini-Player

Version 1.1 adds track numbers to the menu bar mini-player for at-a-glance control.

How It Works

Step 1: Add Music

Browse files, click folders, or drag onto the app icon to build your playlist instantly.

Step 2: Play and Customize

Start playback, rearrange tracks, shuffle, or apply equalizer presets.

Step 3: Edit Metadata

Select tracks, update tags, and save as M4A for lasting changes.

Step 4: Save and Reuse

Export playlists to files or access presets for repeated sessions.

FAQ

Which formats does Viola support?

Standard music files from any folder, excluding protected M4P and Apple Music-specific data.

Can I edit metadata?

Yes, edit and save tags, converting to M4A. Some formats and data types are not editable.

How do I access the mini-player?

Enable in menu bar for quick controls, now with track numbers in version 1.1.

Is this a fully activated version?

Yes, Viola 1.1 is pre-activated. No purchase required—ready to use immediately.
